# Student Identity Kit Pro - Academic Credential & PVC Smart ID Suite

A professional web application for generating high-security PVC Smart ID Cards, Biometric AI Passport Portraits, and complete university academic packages.

## Features
- **CR-80 ISO 7810 PVC Smart Card:** Authentic credit-card proportions with metallic EMV chip, NFC waves, dynamic iridescent hologram seal, microtext security strip, and 3D flip card back.
- **Biometric AI Passport Studio:** Formal studio portraits with 100% solid white backgrounds (#FFFFFF), formal suit and tie attire, front-facing biometric compliance, and client-side canvas background whitening.
- **Dynamic University Crests:** Real vector SVG logos for Bath Spa University, Harvard University, University of Oxford, Cairo University, and Pasadena City College, plus custom logo upload.
- **Academic Package:** Itemized Bursar fee receipt with barcode and stamp, formal admission letter with watermark crest, and embossed enrollment certificate / diploma.
- **Bilingual Interface:** Full English & Arabic (RTL) support.
- **3x Ultra-HD PNG Export:** Instant high-resolution downloads for print or digital verification.
